# 固定版本消费与影子验证

用户选择固定版本包，第一阶段用于研究和影子对照，保留原数据源兜底。

公开仓库只提供市场数据工具与经过来源门禁的版本。消费端匿名读取指定 GitHub 仓库、不可变正式 tag、清单 SHA-256 和 dataset_id；不使用 Latest，不传入私人业务配置或凭据。当前没有正式真实行情 Release，命令应明确失败，不改用合成 artifact。

`fetch-release` 下载至临时目录，限 HTTPS 和 GitHub 资产域名；验证正式、不可变 Release，精确资产白名单和大小上限，固定清单与数据身份，再调用现有 stage-release。失败不改旧缓存和有效指针。只支持公开 Release；私有认证另行实现。

`shadow-check` 只读比较两个有固定清单哈希的消费缓存。重新校验身份、价格和日历哈希，要求相同品种、市场、币种、日线、不复权口径与单位；报告重叠日期、缺日和 OHLCV 差异。默认要求至少 900 个交易日以覆盖 850 日均线及缓冲，双方末日必须等于调用方指定的最近交易日。容差为调用前冻结的相对误差阈值，不事后调参。

报告只输出通用数据状态，不带本地绝对路径；不足历史、过期、缺日、数值差异均不通过。合成数据明确拒绝。单次通过不等于五个交易日验收通过，报告永远不授权生产切换。

私人系统现有 A 股 K 线刷新为 19:30，公开仓库校验为 20:17；前者不能依赖后者当天产物。未来真实发布完成后，消费端在 21:00 后轮询指定版本并校验实际交易日；GitHub 定时任务可能延迟。只先接研究读取器，生产趋势缓存需独立适配、长历史预热和连续五个交易日的只读对照。指数原始日线不能覆盖 ETF 前复权缓存。

本阶段不变更私人应用、业务数据库、有效版本指针、估值、来源权限或生产调度。正式真实数据发布和生产自动同步仍有独立验收项。
