## 身份与接口分开

`canonical_id` 中的 `csi` / `szse` 表示指数身份体系，不指定下载端点。价格数据集默认 `tencent_raw`，另可显式选择 `akshare_eastmoney`。两种来源分别记录上游地址、映射代码、单位、适配器版本和内容哈希。切换来源时产生不同的数据集身份，不静默拼接。

中证与深交所官网仍保留在来源登记中，供将来选择使用；不再是价格取数的默认前提。

## 价格采集

`collect` 按 catalog 中显式登记的指数代码取原始 OHLCV，使用深交所独立整月日历检查请求区间。只接受完整结果；缺日、重复日、额外日期、非法 OHLC、非有限数值或缺原始序列都会失败。输出位于仓库外或忽略的 `data/`，不可覆盖已有快照。

腾讯不使用复权序列；AkShare 调用 `stock_zh_index_daily_em`，底层请求 `fqt=0`。腾讯成交量保存为 `tencent_lots`，东方财富为 `eastmoney_lots`，不做未注明的单位换算。

2026-10-24 逐项实测 2026-10-16 至 2026-10-23：除 930955 外的 10 个指数均通过 6 个交易日的原始日线与独立日历检查。930955 腾讯原始序列缺失，价格数据集已登记为 `akshare_eastmoney`，代码 `csi930955`，成交量单位 `eastmoney_lots`；多年回补时该线上来源不可用，因此没有合格行情快照。这个短区间验收不证明长期历史完整。

## 估值

估值使用独立 `valuation_observation` 数据集，字段固定为 Date、Metric、Value、Unit、Method。已接通乐咕月度 PE/PB、蛋卷当日快照，以及可选的中证历史 PE 对照；PE/PB/股息率不能从 OHLC 推导。整体法、中位数、TTM 和股息率单位分别保留，不与其他发布方序列混用，缺失不补零、不插值。当前没有完整 11 指数估值日历史。

## 定时任务

每日北京时间 20:17 的 Actions 只检查测试、隐私和目录报告。真实本地采集通过 `collect` 或 `backfill` 手动执行；不将本地研究许可自动扩大为 GitHub 云端采集或数据发布。OHLCV、独立收盘价和估值都已有固定版本打包与消费命令，但真实来源的发布许可仍关闭，因此没有可供自动同步的真实 Release。
