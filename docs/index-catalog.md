# 指数数据集与实际来源

12 个登记指数：沪深300 `000300`、中证A500 `000510`、中证500 `000905`、中证1000 `000852`、创业板指 `399006`、创业板R `399606`、科创50 `000688`、中证红利 `000922`、红利低波100 `930955`、中证消费 `000932`、全指医药 `000991`、全指信息 `000993`。

## 身份与接口分开

`canonical_id` 中的 `csi` / `szse` 表示指数身份体系，不指定下载端点。当前价格数据集多数登记为 `tencent_raw`，000932／000991／000993 为 `csindex_official`，930955 为 `akshare_eastmoney`；另可对已登记映射显式选择 `sina_raw` 等来源。各来源分别记录上游地址、映射代码、单位、适配器版本和内容哈希。切换来源时产生不同的数据集身份，不静默拼接。

创业板R `399606` 是创业板全收益序列，`399006` 是价格指数；二者数值、收益含义和发布起点不同，不能互换或合并。全收益序列进入研究、消费器及回测元数据时保留 `series_type=total_return_index`。

中证与深交所官网仍保留在来源登记中，供显式选择。中证官网不是价格取数的默认前提；只有来源明确选择为 `csindex_official` 的数据集才走该接口。

## 新指数的历史门槛

A500 `000510` 的首个官方历史日为 `2024-09-23`；科创50 `000688` 的基础日为 `2019-12-31`，正式发布日为 `2020-07-23`。这两类新指数不能仅因为不足 900 个交易日就被当成坏数据，但豁免只适用于“从该指数首个官方日期起覆盖连续、无缺日、末日正确”的序列。850 日均线不到 850 行时继续显示为空，不会为凑数缩短均线窗口或向前借用其他指数历史。

创业板R 的基础日为 `2010-05-31`，首个可验证发布观测为 `2010-06-02`。当前腾讯历史仅有收盘序列可用，该轮结果可用于研究收盘和均线；不能作为完整 OHLCV 进入回测或生产 OHLC 路由。

## 价格采集

`collect` 按 catalog 中显式登记的数据集来源与指数代码取原始 OHLCV，使用深交所独立整月日历检查请求区间。只接受完整结果；缺日、重复日、额外日期、非法 OHLC、非有限数值或缺原始序列都会失败。输出位于仓库外或忽略的 `data/`，不可覆盖已有快照。

`collect --provider` 可选腾讯、新浪和 AkShare/东方财富；中证官方由数据集的 `source` 选择，不是该参数的选项。`backfill` 按数据集默认来源回补，不自动遍历备用源。

腾讯不使用复权序列；AkShare 调用 `stock_zh_index_daily_em`，底层请求 `fqt=0`。腾讯成交量保存为 `tencent_lots`，东方财富为 `eastmoney_lots`，不做未注明的单位换算。

## 估值

估值使用独立 `valuation_observation` 数据集，字段固定为 Date、Metric、Value、Unit、Method。已接通乐咕月度 PE/PB、蛋卷当日快照，以及可选的中证历史 PE 对照；PE/PB/股息率不能从 OHLC 推导。整体法、中位数、TTM 和股息率单位分别保留，不与其他发布方序列混用，缺失不补零、不插值。当前没有完整 12 指数估值日历史。

## 定时任务

每日北京时间 20:17 的 `check` Actions 检查测试、隐私和目录报告。`daily index release` 每天 21:40、23:40 和次日 09:00 检查上一版之后是否有已闭市但尚未发布的交易日：只有数据齐备时才生成补缺批次和新的累计固定版本；没有缺失会话时直接结束。第一次使用 `bootstrap=true` 建立全量基线；后续版本下载上一版累计包、复验其清单与哈希、追加全部连续缺失会话，再发布新的累计包。周五延迟到周六的数据仍以周五日期发布，不生成周末空版本。详见[每日累计发布](daily-release.md)。
