## 公开边界

公开仓库从经过审查的代码快照开始，未导入旧仓库的提交、PR、Actions 日志或附件。旧仓库保留为私有历史备份。公开 Git 文件仅包含通用代码、目录、文档和明确标注的合成样例，不包含真实采集结果、私人应用文件、账户、持仓、账本或凭据。

代码可公开不代表真实行情已获公开再分发许可；价格和独立交易日历分别核查当前权限。真实来源的云端采集、保存和发布开关仍关闭。不得为通过门禁临时放开来源权限。

## 生产接入与失败恢复

使用方式见[消费端契约](consumer-integration.md)。当前 `stage-release` 只验证并安装固定版本，不联网、不改有效版本指针、不写数据库。生产下载器、定时任务、五个交易日影子对照、指标缓存适配与估值导入尚未启用。

新增 `fetch-release` 提供固定公开版本的下载组件，`shadow-check` 提供一次只读差异报告；两者不注册后台定时任务，不授权切换生产。同一消费目录自我对照仅是读取冒烟，不能累计成五日独立对照。当前来源门禁未开启真实云端发布，因此尚无可供正式同步的真实行情 Release。

来源不可达、缺日、错误哈希、过期、撤回或缓存损坏时拒绝新版本，继续保留上一有效版本；不自动换源、补零或拼接历史。正式数据发布前还需核对差异报告与当前来源权限。

代码 clone 不包含 Release 附件。正式使用后，独立归档需保存 commit、Release 清单、SHA256SUMS、数据包和撤回登记，并定期从归档恢复、重新验算。网页只读已经生效的缓存，不能在请求期间下载全历史数据。
