## 生产接入与失败恢复

使用方式见[消费端契约](consumer-integration.md)。`stage-release` 与 `stage-snapshot-release` 只验证并安装调用方锁定的固定版本，不联网、不改有效版本指针、不写数据库。`fetch-release` 与 `fetch-snapshot-release` 是匿名下载组件，`shadow-check` 提供一次只读差异报告；它们不注册后台定时任务，不授权切换生产。

完整 OHLCV、独立收盘价和估值观测都已有打包、验算与消费路径。五个交易日影子对照、生产指标缓存适配和私人业务库导入尚未启用。同一消费目录自我对照仅是读取冒烟，不能累计成五日独立对照。当前来源门禁未开启真实云端发布，因此尚无可供正式同步的真实行情或估值 Release。

来源不可达、缺日、错误哈希、过期、撤回或缓存损坏时拒绝新版本，继续保留上一有效版本；不自动换源、补零或拼接历史。正式数据发布前还需核对差异报告与当前来源权限。

代码 clone 不包含 Release 附件。正式使用后，独立归档需保存 commit、Release 清单、SHA256SUMS、数据包和撤回登记，并定期从归档恢复、重新验算。网页只读已经生效的缓存，不能在请求期间下载全历史数据。
